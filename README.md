# Radon Shield Cincinnati

Create a premium, modern, high-converting website for a local home service business called **Radon Mitigation Cincinnati**.

The website should feel trustworthy, clean, and professional—similar in quality to premium contractor websites. The goal is to generate phone calls and quote requests from homeowners throughout the Greater Cincinnati area.

## Design Direction

Style:

- Modern and minimal

- Premium home services brand

- Clean spacing

- Rounded corners

- Soft shadows

- Large photography

- Smooth animations

- Mobile-first

- Fast loading

- SEO-friendly

Primary Colors

- Deep Navy (#0F2742)

- Bright Blue (#1E73E8)

- White (#FFFFFF)

Accent Colors

- Success Green (#22C55E)

- Light Gray (#F8FAFC)

- Dark Text (#111827)

Typography

- Large bold headings

- Modern sans-serif (Inter or Manrope)

- Excellent readability

Use high-quality stock photography throughout from Unsplash or Pexels including:

- Family in a modern home

- Basement

- Radon mitigation system

- Technician installing PVC vent pipe

- Home inspection

- Cincinnati skyline

- Happy homeowners

- Professional HVAC/service technician

- Beautiful suburban homes

Do not use cartoon illustrations.
